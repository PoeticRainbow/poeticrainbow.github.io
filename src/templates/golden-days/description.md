# Golden Days: A Minecraft Time Machine.

Golden Days is a texture pack for Minecraft: Java Edition that sends your game back in time. It changes blocks, items, mobs, sounds, music, GUI elements, and even more to be inspired by the past.

Golden Days takes advantage of many advanced features introduced to recreate the original Minecraft experience as much as possible. There is also mod support to allow customizable toggleable options in the game via the PolyTone mod! Use these options to tweak your game to send yourself to the exact version of Minecraft makes you feel the most nostalgic or coziest.

## Golden Days Base

The classic 2011 experience of Minecraft. Heavily based on Beta 1.6.6 (with customization options via PolyTone to range from Beta 1.3 - Release 1.6)! Intended to be fully functional in survival gameplay without removing any modern content.

Many modern blocks and items are redone in Golden Days to give them that old Beta Minecraft aesthetic. More and more are added with every update!

This pack includes everything you need for an authentic Beta experience. You **must** apply Programmer Art below Golden Days Base or else you will be missing textures. Golden Days does not redistribute these assets as they are officially available within the game itself.

## Golden Days Alpha

The Alpha Addon will transport your game even further into the past, including the iconic Alpha grass and foliage colors! Enjoy the neon green fields and forests alongside other older textures and models such as those bright red Bricks and ore blocks like Gold and Iron! This pack must be applied on top of Golden Days Base or else you will have broken content.

There is further customization available with the Alpha addon via the PolyTone mod. Do you want those Classic Wool and Dye colors? They are available via options!

## Client Mod Support:

This pack has **extended capabilities** using some modded features:

- Config Options (Chest Model, Cobblestone texture..., requires PolyTone)
- Custom Particles (found in the Pale Garden..., requires PolyTone)
- Modifiers (Block, Item, Biome, Dimension, Fluid..., requires PolyTone)
- Custom Colors (Dyed Sheep, Text Colors, Fireworks..., requires PolyTone)
- Custom Entity Models (Boats, Zombie Pigmen, Allays, Bats..., requires EMF)

### Directly Supported:

[PolyTone](https://modrinth.com/mod/polytone): Adds many resource pack capabilities. Config Options, Custom Colors, block properties, etc.

[Entity Model Features](https://modrinth.com/mod/entity-model-features): Gives Golden Days the ability to modify entity models.

### Pairs Well:

[Nostalgic Tweaks](https://modrinth.com/mod/nostalgic-tweaks): A mod for Fabric/Forge that adds a whole ton of old Minecraft tweaks! It is really cool!

[Retro Tweaks](https://modrinth.com/mod/retro-tweaks): A mod inspired by Nostalgic Tweaks for Fabric/NeoForge for newer Minecraft versions! (Currently 1.21.11, under review)

[Moderner Beta](https://modrinth.com/mod/moderner-beta): Adds accurate beta and alpha generation back into Minecraft!

### Not Supported:

OptiFine: No longer the intended experience as open source replacements are available.
